# 2026-09-27：独立添加窗口与跨窗口保存

这是一份历史实现记录。相关改动已纳入当前源码；当前项目入口和验证状态见 [项目档案](../PROJECT.md)，人工步骤见 [验收清单](../DESIGN_CHECKLIST.md)。

## 独立窗口

- 新增异步 `open_add_stock` 和 `close_add_stock`，窗口标签为 `add-stock`，设计内尺寸 420×360 逻辑像素、常规最小尺寸 320×240。重复打开聚焦同一窗口；退出应用时关闭所有附属窗口。
- 设置窗与添加窗按主窗所在屏幕的工作区定位，小工作区按可用范围收缩。多 DPI、负坐标多屏与极小工作区仍需原生现场验证。
- 前端按 `main`、`settings`、`add-stock` 三种角色启动。仅主窗运行行情轮询、快捷键和窗口自动尺寸逻辑；浏览器预览沿用页面内降级界面。
- 添加窗使用不透明背景，固定代码列和可伸缩名称列，不继承行情条的低透明度。保存失败保留输入供重试。
- `add-stock` 使用独立 Tauri capability，仅授予 `core:default`，未新增任意 URL 代理权限。

## 请求与保存

`src/windowContract.ts` 定义添加和设置保存的请求、结果及运行时校验。附属窗口注册定向 ACK 监听后发送请求；8 秒未收到确认时保留输入和请求 ID。主窗串行处理写入，持久化成功后才回复成功，重试不会重复添加。

设置窗提交草稿，由主窗按最新自选合并保存。恢复默认时保留弹窗打开期间新增的股票。主窗排序、删除和样式修改也沿用单点写入路径。

保存开始后锁定全部草稿控件，并记录原禁用状态；成功、错误或超时后恢复。原样重试沿用请求 ID，修改草稿后生成新 ID。状态规则位于 `src/settingsSubmission.ts`。
