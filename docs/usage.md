# 使用指南

## 自选与窗口

主窗口仅显示当前自选的股票和指数。右键打开菜单，在走马灯和列表之间切换；列表模式支持自选置顶、上移、下移、置底和表头显示。右键股票时可删除该项，右键空白处不会出现删除股票操作。

「添加股票」打开独立搜索窗口，支持六位代码、部分代码、中文名称和简称拼音首字母。结果固定显示代码和名称，已添加的项目不可重复添加。添加成功后窗口关闭并刷新行情；保存失败时保留输入供重试。断网时仅能搜索内置常用股票。

主窗口关闭按钮会隐藏到托盘。`Alt+1` 或托盘菜单可以恢复窗口，完全退出使用「退出应用」。隐藏程序框后仍可通过行情区域的右键菜单操作。

## 设置与保存

设置在独立窗口中编辑，点击「保存设置」后才生效。取消、Esc 或关闭未提交的设置窗口会撤销草稿；保存过程中请等待结果。设置窗口打开期间添加的新股票会保留。

「恢复默认」会重置原有自选和外观；设置窗口打开期间新增的股票会保留。至少选择一个显示字段。更新时间和程序框可分别隐藏；隐藏更新时间不会隐藏演示数据或行情缺失提示。

## 导出、导入与恢复

1. 在设置窗口导出当前已保存配置。可下载 JSON；若原生窗口没有出现保存提示，可复制 JSON 文本保存。
2. 导入 JSON 文件或粘贴文本，内容先载入设置草稿。检查自选与外观后点击「保存设置」写入；取消不会替换现有配置。
3. 导入写入前会保留一个本地恢复点。需要撤销时载入「导入前恢复点」，检查草稿并保存。后续导入可能更新这个恢复点，请保留自己的导出文件。

文件上限为 128 KiB，自选上限为 200 项。未来格式版本、无效字段或重复股票等不符合约定的内容会被拒绝。恢复时会保留设置窗口打开期间新增的自选；写入失败不会报告为保存成功。

设置保存在应用 WebView 的 `localStorage`，主键为 `zoumadeng.settings.v1`。卸载、清理 WebView 数据或更换 Windows 用户可能造成配置丢失。配置文件包含自选列表，分享前请检查。

## 如何理解行情状态

- 正常行情：本机刷新时间代表请求完成时间；悬停股票查看的数据源时间代表数据提供方标注的时间，两者可能不同。
- 部分缺失：股票保留原位置，缺失字段显示 `--`，不混入演示数值。
- 请求失败：显示明确的「演示数据」标记；网络恢复并成功取得行情后恢复在线内容。
- 空自选：添加股票或指数后开始显示对应行情。

单次行情请求（包括响应体读取）最多等待 10 秒，响应上限为 2 MiB。数据依赖第三方接口，可能延迟、缺失或中断。项目不提供交易执行服务。

## 遇到问题

请通过 [GitHub Issues](https://github.com/dingding-abc/zoumadeng/issues) 反馈，并说明应用版本、Windows 版本、具体操作和结果。窗口位置或大小问题请附上显示器数量、缩放比例和截图；公开截图前可遮挡个人信息。
