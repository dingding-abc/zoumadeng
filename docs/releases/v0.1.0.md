# 走马灯行情 v0.1.0

首个公开版本，让自选股票和指数常驻 Windows 桌面。

## 下载与安装

下载 `zoumadeng_0.1.0_x64-setup.exe`，适用于 Windows 10/11 x64，需要 WebView2 Runtime。安装后从开始菜单打开「走马灯行情」。首次使用在行情区域点击右键，可添加股票、切换视图和打开设置；`Alt+1` 显示或隐藏窗口。

本次发布使用维护者现有的 NSIS 安装包，文件生成时间为 **2026-10-06 14:40:51（UTC+08:00）**，大小 **3,540,766 字节**。上传文件名采用英文以兼容 GitHub 附件命名，安装包内容保持原样，本次没有重新编译。该文件未进行 Authenticode 数字签名，Windows 可能显示未知发布者提示，请核对下载来源和文件摘要。

## 功能

- 横向走马灯与紧凑列表，可自定义字段、字号、滚动速度、颜色和透明度。
- 按代码、名称、拼音首字母搜索，在独立窗口添加自选；支持删除与列表排序。
- 托盘菜单、`Alt+1` 快捷键、程序框和更新时间显示开关。
- JSON 配置导入导出、导入草稿预览和导入前恢复点。
- 明确区分在线行情、部分缺失和演示数据状态。
